# Cat vs Dog Classification 

This project uses **ResNet18 (CNN)** to classify images as **Cat** or **Dog**.

## Technologies

* Python
* PyTorch
* Torchvision
* NumPy
* Matplotlib
* Jupyter Notebook

## Model

* Pretrained **ResNet18**
* Image size: **224 × 224**
* Optimizer: **Adam**
* Loss: **Cross-Entropy Loss**
* Batch size: **32**

## Project Structure

```text
├── TP5_Problem5_CNN(1).ipynb
├── cat_dog/
├── catdog_cnn_weights.pth
└── README.md
```

## How to Run

1. Install the required libraries:

```bash
pip install torch torchvision numpy matplotlib pillow
```

2. Open the notebook:

```text

```

3. Run the cells from top to bottom.
